## Структура проєкту
Кожне завдання реалізовано в окремому модулі:
* `task1.py` — Списки: індексація, зрізи та мутації.
* `task2.py` — Кортежі та «розпакування» даних.
* `task3.py` — Словники та облік частот.
* `task4.py` — Множини: унікальність та операції над наборами.
* `task5.py` — Алгоритмічна складність (порівняння list та set).

## Інструкція із запуску
Проєкт використовує виключно стандартну бібліотеку Python (вбудовані модулі, такі як `time`). 
Для перевірки роботи скриптів запускайте кожен файл окремо через термінал або командний рядок:

```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
